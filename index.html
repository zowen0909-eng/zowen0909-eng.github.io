GitHub Gist 云同步配置

配置 GitHub Gist 实现数据自动云同步。需要在 GitHub 上创建一个 Gist 并生成个人访问令牌（Token）。
创建 Gist 后，浏览器地址栏中的 ID（gist.github.com/用户名/这里）
GitHub 设置 > Developer settings > Personal access tokens > Tokens (classic) > 勾选 gist 权限
用于标识这个 Gist 的名称
如何创建 Gist 和 Token（详细步骤）

第一步：创建 Gist

  1. 打开 gist.github.com
  2. 在 "Filename including extension" 输入框填写：backup.json
  3. 在下面的代码框随便输入一个字符（如 1）
  4. 选择 "Create secret gist"（私密 Gist）
  5. 创建成功后，复制地址栏中的 ID

第二步：创建 Token

  1. 打开 GitHub 设置：https://github.com/settings/settings
  2. 滚动到底部点击 "Developer settings"
  3. 点击 "Personal access tokens" > "Tokens (classic)"
  4. 点击 "Generate new token" > 选择 "Generate new token (classic)"
  5. 在 scopes 中只勾选 gist 这一项
  6. 点击 "Generate token" 按钮
  7. 复制生成的 token（格式如 ghp_xxxxxxxxxxxx）

第三步：配置

  1. 把 Gist ID 和 Token 填入上面的输入框
  2. 点 "保存配置"
  3. 点 "测试连接" 验证是否成功
